# Simple React Portfolio

A clean, responsive portfolio built with React, Vite, Lucide icons and plain CSS. Its visual direction is light, editorial and minimal, distinct from a dark technical portfolio.

## Run it
1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in VS Code.
3. Open Terminal and run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the localhost URL shown by Vite (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
npm run preview
```

## Personalize before publishing
- Replace `Alex Morgan` in `src/App.jsx` and `index.html` with your name.
- Replace `hello@example.com` with your real public email.
- Replace the GitHub and LinkedIn links with your profiles.
- Update sample project descriptions to reflect actual work and link each project to the correct repository or demo.
- Adjust the skills and experience to accurately represent your background.

## Main files
- `src/App.jsx`: sections, project cards, skill filtering and responsive menu.
- `src/styles.css`: complete visual design and mobile styles.
- `src/main.jsx`: React app entry point.
- `index.html`: page metadata.
